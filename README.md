# Crystal Lab

재료공학의 핵심 개념(결정구조, 결함, Fe-C 상태도, 기계적 거동)을 직접 돌려 보고 눌러 보며 익히는 인터랙티브 시각화 웹앱입니다. O/X 퀴즈로 복습할 수 있습니다.

**바로 사용하기 → https://minsikkim2.github.io/crystallab/**

설치나 빌드 없이 브라우저에서 바로 열립니다. 데스크톱과 모바일 모두 지원하고, 시스템 설정에 따라 다크/라이트 테마가 자동으로 적용됩니다.

## 탭 구성

### 1. 결정구조
- BCC · FCC · HCP · Diamond Cubic 단위셀 3D 뷰 (드래그 회전, 스크롤 확대, 시점 프리셋)
- 단위셀 원자 수, 배위수, 충전율(APF), 격자상수 등 구조별 물성
- 원자를 클릭해 결정방향 [uvw] · 결정면 (hkl) 분석, Miller 지수 입력 시각화
- BCC/FCC **팔면체 간극** 표시 (BCC 0.155R 찌그러진 팔면체 vs FCC 0.414R 정팔면체)와 확대 보조 창

### 2. 결함 (Defects)
| 분류 | 유형 |
|---|---|
| 점결함 | 공공, 자기침입형, 침입형 불순물(BCC/FCC 간극 비교 · 정방정 왜곡), 치환형 불순물, 쇼트키, 프렌켈 |
| 선결함 | 칼날 전위(응력장 · 글라이드 애니메이션), 나사 전위(교차 슬립), 혼합 전위, Frank-Read 전위원(단계별 애니메이션) |
| 면결함 | 결정립계(소경각 · 대경각), 쌍정 경계(어닐링 · 변형), 적층결함(내재형 · 외재형) |

공공 농도, Hume-Rothery 크기 조건, Hall-Petch, 가공경화(τ = τ₀ + αGb√ρ), 적층결함 에너지와 부분 전위 간격 등의 계산기가 함께 있습니다.

### 3. Fe-C 상태도
- 준안정 Fe–Fe₃C 상태도 (액상선, 고상선, A₁, A₃, Acm, 솔버스선, 공석 · 공정 · 포정점)
- 마우스를 올리면 온도 · 탄소 함량 · 상 표시, 영역을 클릭하면 상세 정보
- 단상 영역(α, γ, δ): 탄소가 팔면체 간극에 들어간 3D 단위셀, 간극 크기표, 침입형 고용체 설명
- 2상 영역: 공액선(tie line)과 **지렛대 규칙** 계산, 조성 · 온도에 맞춘 미세조직 설명
- 보기 범위: 전체 / 강(0–2.2%) / 저탄소(0–0.25%)

### 4. 기계적 거동
- 재료 7종 응력-변형률 곡선 비교: 저탄소강, 구리, 황동, Al 6061-T6, 304 스테인리스, 회주철, Ti-6Al-4V
- 비례한도 · 0.2% 항복(상/하항복점) · UTS · 파단점 마커, 0.2% offset 작도선
- 그래프를 드래그하는 **응력 수평선**: 탄성 → 항복 → 가공경화 → 네킹 → 파괴 상태와 미시적 설명이 따라 바뀜
- 공칭 ↔ 진 응력-변형률 전환, 인성 · 레질리언스 면적 표시
- 재료 물성표, 선택한 재료끼리의 비교 인사이트 자동 생성

### 5. 퀴즈
- 4개 영역 + 전체 랜덤, 문제 은행 128문항(영역별 32문항)과 숫자가 매번 바뀌는 변형 문제 생성기 9종
- 틀리면 힌트를 먼저 보여 주고, 두 번째에 정답 공개. 틀린 문제는 몇 문제 뒤에 복습으로 다시 출제
- 해설에서 "관련 탭에서 확인하기"를 누르면 해당 탭의 해당 화면으로 이동
- 영역별 정답률과 최고 연속 정답은 브라우저(localStorage)에 저장
- 키보드: `O` / `X` 또는 `←` / `→`로 답하기, `Enter`로 다음 문제

## 로컬에서 실행

`index.html` 하나로 이루어진 정적 페이지입니다. 파일을 브라우저로 바로 열어도 되고, 로컬 서버로 띄워도 됩니다.

```bash
python3 -m http.server 8090
```

그다음 http://localhost:8090 을 엽니다. Three.js와 웹폰트를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 기술 구성

- 단일 HTML 파일 (HTML · CSS · JavaScript, 빌드 도구 없음)
- [Three.js r128](https://threejs.org/): 3D 결정구조 · 결함 시각화 (z축이 위쪽인 구면좌표 궤도 카메라)
- SVG: Fe-C 상태도, 응력-변형률 그래프
- 폰트: IBM Plex Sans KR, JetBrains Mono
- 배포: GitHub Pages (`main` 브랜치에 푸시하면 자동 반영)

## 데이터와 근사에 대해

교육용 시각화이므로 아래 값들은 교과서(Callister 등)와 ASM Handbook 수준의 대표값이며, 일부는 근사입니다.

- **Fe-C 상태도**: 특성점(공석 0.76%/727°C, 공정 4.30%/1147°C, 포정 0.17%/1495°C 등)은 표준값입니다. 곡선 중간은 문헌값 여러 점을 이은 근사라 수십 °C 정도 차이가 날 수 있습니다.
- **응력-변형률 곡선**: 각 재료의 E, σy, UTS, %EL, %RA, n에 맞춘 모델입니다.
  - 어닐링 FCC(Cu, 황동, 304)는 Ludwik 식, Al-T6 · Ti 합금 · 저탄소강은 Swift 식으로 가공경화를 표현합니다.
  - 네킹은 Considère 조건에서 시작합니다. 네킹 이후 진응력은 실제 네킹 단면 기준이며, 파단 진변형률은 ln(1/(1−RA))로 계산합니다.
- **결함 시각화**: 원자 변위, 응력장, 입계 구조는 개념을 보여 주기 위한 단순화 모델입니다.
